# Simple REC

A simple screen recorder for Mac that your AI assistant can use. Record, then let Claude Code or Codex help you edit and learn from other videos.

- Website: https://simplerec.teamgoldllc.de
- Beta access: the download needs a beta code. Ask for one at https://teamgoldllc.de/contact
- Requires an Apple silicon Mac (M1 or newer) with macOS 15 or newer.

**Beta note:** the app is not notarized by Apple yet. On first launch open System Settings → Privacy & Security → "Open Anyway".

The source code is private. Simple REC is built by TEAM GOLD LLC. Questions or ideas: https://teamgoldllc.de/contact
